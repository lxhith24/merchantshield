# Six-file video fixture

Select all six CSV files together in **Check merchants**, then choose
**Run live check**. Each file contains one synthetic merchant. Together they
form a new linked group through a shared settlement-account token, two shared
device groups, paired IP addresses, paired addresses and a one-minute
submission window.

These are synthetic demonstration records only. They are intentionally obvious
enough to make the upload interaction reliable on camera; they are not part of
the held-out metric claim and are not proof of production performance.
